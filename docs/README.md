# BareZen-Drive 文档索引

本目录收录 BareZen-Drive 的架构、API、开发与路线图文档。当前版本 v0.0.1。

[English](README.en.md) | [简体中文](README.md)

## 文档列表

- [architecture.md](architecture.md)：总体架构、模块布局、服务端与客户端结构、数据模型、上传协议、
  客户端国际化（i18n）、检查更新与部署说明。
- [api.md](api.md)：REST API 参考，覆盖认证、文件夹、文件、上传、缩略图、签名链接、相册、公开
  分享与版本查询，含错误码全集。
- [development.md](development.md)：本地开发指南，包含 JDK 与 Android SDK 要求、服务端与客户端
  运行命令、测试命令、持续集成说明以及一键部署步骤。
- [roadmap.md](roadmap.md)：已完成范围、进行中的条目、后续规划，以及已知技术债。

## 建议阅读顺序

1. 先读仓库根目录的 [README.zh-CN.md](../README.zh-CN.md)，了解产品定位、功能特性、模块表与快速
   开始。
2. 再读 [architecture.md](architecture.md)，建立整体架构与数据模型的概念。
3. 需要对接接口时读 [api.md](api.md)。
4. 需要搭建环境或部署时读 [development.md](development.md)。
5. 需要了解版本范围与后续计划时读 [roadmap.md](roadmap.md)。
